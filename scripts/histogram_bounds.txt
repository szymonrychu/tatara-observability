# Histogram bucket-ceiling provenance. scripts/lint_alert_rules.py Check 4 fails CI
# when an alert thresholds a histogram_quantile() outside the range that quantile can
# actually return. This exists because two p95 rules compared against `> 30` over
# histograms topping out at 25.6s and 10s (tatara-observability#111): classic
# histogram_quantile returns AT MOST the top finite bucket bound, so both rules were
# mathematically unable to fire on any input, ever - and every alert file sets
# default_no_data_state: "OK" while grafana.tf sets default_exec_err_state = "OK", so
# neither went stale and neither errored. They read green because they could not read
# anything else. That is the same silent-green class as an alert on a metric nobody
# emits (scripts/metrics_allowlist.txt) and an alert filtering on a label value nobody
# emits (scripts/stage_values_allowlist.txt), one level further down.
#
# FORMAT: `<metric family> <top finite bucket bound>`, one per line, grouped under
# `# --- <section>: ... ---` headers. The section key is the leading word of the header
# text and routes to a producer repo through reconcile_metric_provenance.py's
# SECTION_REPO, exactly as in metrics_allowlist.txt. List the BASE family name (no
# _bucket/_sum/_count suffix), matching the `<family>_bucket` selector an alert writes.
#
# THIS FILE IS VALIDATED, NOT TRUSTED. A hand-transcribed copy of a number that lives in
# another repo goes stale the day a producer widens its buckets, and a stale ceiling here
# would block a threshold that has become legal - a red build on a correct rule, which is
# how a check gets weakened to a warning. So reconcile_metric_provenance.py re-derives
# every bound below from the producer repo's own Go source on each run and HARD-FAILS on
# any mismatch. This is the same reverse-drift gate metrics_allowlist.txt got in #57,
# applied to the bound rather than the name.
#
# A family whose `Buckets:` is a named package-level variable is NOT derivable by that
# reconciler and is deliberately absent below rather than guessed:
#   - code_graph_analytics_duration_seconds (tatara-memory, analyticsDurationBuckets)
#   - http_request_duration_seconds         (tatara-memory, requestDurationBuckets)
# No alert runs a quantile over either today. A rule that starts to will hard-fail Check 4
# until its bound is added here by hand; add it with a comment naming the var, and the
# reconciler will report it as unvalidatable rather than failing on it.
#
# ExponentialBuckets(start, factor, count) tops out at start * factor^(count-1).
# LinearBuckets(start, width, count) tops out at start + width*(count-1).
# prometheus.DefBuckets tops out at 10.
